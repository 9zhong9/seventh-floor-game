# 第七码楼

手机浏览器可玩的文字恐怖闯关游戏原型。

## 在线游玩

启用 GitHub Pages 后访问：

`https://9zhong9.github.io/seventh-floor-game/`

## 文件

- `index.html`：页面结构
- `style.css`：手机响应式样式
- `game.js`：剧情、分支、数值和本地存档
- `manifest.json`：添加到手机主屏幕的配置

## 内容警告

本作含虚构的血腥、死亡、暴力与心理恐怖内容。主要角色均为明确成年的虚构人物；不含露骨色情描写。

## 本地存档

存档使用浏览器 `localStorage`，只保存在当前设备和浏览器中。
